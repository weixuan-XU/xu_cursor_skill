# Example Skill（徐原创模板）

作者：徐（[weixuan-XU](https://github.com/weixuan-XU)）

把本文件改成你的 skill 说明。Agent 会按这里的步骤执行。

## 何时使用

- 用户说了会触发本 skill 的关键词或场景（写在上方 `description` 里）

## 步骤

1. 确认用户目标与约束
2. 按本 skill 约定的流程执行
3. 交付结果并说明做了什么

## 输出

说明期望的交付物格式（文件、报告、代码改动等）。
